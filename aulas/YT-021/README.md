# YT-021 — Coortes e retenção: uma análise avançada passo a passo

## Objetivo

Aprenda a construir uma análise de coortes no PostgreSQL, do mês da primeira atividade até a matriz de retenção. No DBeaver, vamos calcular o mês relativo, contar clientes ativos e transformar os totais em percentuais comparáveis — sem tratar períodos futuros como abandono.

## Comandos e consultas usados na aula

Execute os arquivos na ordem abaixo no DBeaver. Quando houver `setup.sql`, use-o primeiro para preparar o laboratório local.

- [`coortes_retencao.sql`](coortes_retencao.sql)
- [`setup.sql`](setup.sql)

## Como executar

1. Inicie o PostgreSQL conforme o [README principal](../../README.md).
2. Abra uma conexão com o banco `vendas` no DBeaver.
3. Abra cada arquivo SQL desta pasta na ordem indicada.
4. Execute uma consulta por vez e confira o grid de resultados.
