# YT-024 — Projeto final: análise completa de um e-commerce com SQL

## Objetivo

Feche a série construindo uma análise executiva reproduzível de um e-commerce. No DBeaver, vamos definir os principais indicadores, acompanhar a evolução mensal, comparar canais de venda e identificar clientes prioritários sem perder a granularidade nem a consistência das métricas.

## Comandos e consultas usados na aula

Execute os arquivos na ordem abaixo no DBeaver. Quando houver `setup.sql`, use-o primeiro para preparar o laboratório local.

- [`projeto_final.sql`](projeto_final.sql)
- [`setup.sql`](setup.sql)

## Como executar

1. Inicie o PostgreSQL conforme o [README principal](../../README.md).
2. Abra uma conexão com o banco `vendas` no DBeaver.
3. Abra cada arquivo SQL desta pasta na ordem indicada.
4. Execute uma consulta por vez e confira o grid de resultados.
