# YT-018 — Qualidade de dados com SQL: nulos, duplicados e regras inválidas

## Objetivo

Aprenda a validar uma carga no PostgreSQL antes de calcular indicadores: medir nulos, localizar campos obrigatórios ausentes, encontrar chaves duplicadas, testar domínios e limites numéricos e consolidar um relatório reutilizável de qualidade.

## Comandos e consultas usados na aula

Execute os arquivos na ordem abaixo no DBeaver. Quando houver `setup.sql`, use-o primeiro para preparar o laboratório local.

- [`data_quality.sql`](data_quality.sql)
- [`setup.sql`](setup.sql)

## Como executar

1. Inicie o PostgreSQL conforme o [README principal](../../README.md).
2. Abra uma conexão com o banco `vendas` no DBeaver.
3. Abra cada arquivo SQL desta pasta na ordem indicada.
4. Execute uma consulta por vez e confira o grid de resultados.
