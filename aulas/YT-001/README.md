# YT-001 — SQL para Analistas: o mapa do básico ao avançado

## Objetivo

SQL não é uma coleção de comandos para decorar. É a ferramenta que conecta perguntas de negócio a respostas verificáveis.


Neste primeiro vídeo da série, você vai entender:
- onde o SQL entra no trabalho de um analista;
- por que granularidade e validação importam desde o começo;
- como o mesmo projeto de e-commerce evolui dos fundamentos até funil, coortes, retenção e performance;
- qual ordem seguir para aprender sem acumular lacunas.

Ao longo da playlist, usaremos PostgreSQL, DBeaver e um dataset sintético de e-commerce com clientes, produtos, pedidos, itens e eventos. Os episódios práticos mostram a execução real; os conceituais preparam o raciocínio que evita consultas plausíveis, porém erradas.

Exercício deste vídeo: escreva uma pergunta de negócio em linguagem comum e liste os dados necessários para respondê-la. Ainda não escreva a consulta.

Próximo vídeo: ambiente pronto com PostgreSQL, DBeaver e o banco de vendas.

## Atividade

Esta aula é conceitual. Use o exercício proposto no vídeo e registre sua pergunta de negócio antes de avançar para a prática.
