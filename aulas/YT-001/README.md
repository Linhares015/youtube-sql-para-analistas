# Aula YT-001 — O mapa do SQL para analistas

## Objetivo

Entender como uma pergunta de negócio se transforma em dados, consulta, validação e decisão.

## Exercício

Antes de escrever SQL, escolha uma pergunta de negócio e registre:

1. a decisão que será apoiada;
2. a métrica necessária;
3. o grão esperado do resultado;
4. as tabelas ou eventos necessários;
5. uma checagem para validar a resposta.

Na próxima aula, o ambiente e o banco de vendas serão preparados.
