# YT-023 — Boas práticas de SQL profissional: padrão, revisão e manutenção

## Objetivo

Aprenda a transformar uma consulta que apenas executa em SQL que o time consegue revisar e manter. No DBeaver, vamos aplicar um padrão legível, separar regras com CTE, criar validações explícitas e centralizar parâmetros de data no projeto contínuo de e-commerce.

## Comandos e consultas usados na aula

Execute os arquivos na ordem abaixo no DBeaver. Quando houver `setup.sql`, use-o primeiro para preparar o laboratório local.

- [`boas_praticas.sql`](boas_praticas.sql)
- [`setup.sql`](setup.sql)

## Como executar

1. Inicie o PostgreSQL conforme o [README principal](../../README.md).
2. Abra uma conexão com o banco `vendas` no DBeaver.
3. Abra cada arquivo SQL desta pasta na ordem indicada.
4. Execute uma consulta por vez e confira o grid de resultados.
